OpenKnowledge presents a local-first Markdown editor with agent access through MCP. Its repository and overview describe an editor, an agent interface and Markdown files as complementary layers.[^s1][^s2][^s3]

## This library

Content is written through the application's CRDT-aware tools. Portable Markdown links connect source records, curated notes and project pathways. PDF originals and local images support human reading while the text remains meaningful without them.
