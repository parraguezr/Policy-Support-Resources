Soft systems modelling structures inquiry into situations where people disagree about the problem, its boundaries or desirable outcomes. Rich pictures and conceptual models help compare perspectives with real-world practice.[^s1]

## How to use

Engage affected groups, surface different definitions of the situation, build purposeful activity models, and discuss changes that are both desirable and feasible. Facilitation is part of the method, not an optional presentation layer.

## Evidence and limitations

The result is a structured learning process rather than a single objectively correct systems diagram. It requires time and participation; an analyst-generated model can conceal disagreement.

## Suggested project use

Use before fixing a common taxonomy or policy problem statement. In UNDP workshops, preserve competing interpretations of the same documents. For MinCiencia, clarify whose needs a resource-discovery system serves.

## Relationships
