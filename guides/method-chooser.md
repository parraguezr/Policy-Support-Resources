This is an editorial navigation aid. Follow each method to its source and limitations before applying it.

| Your question | Start with | What it does not establish by itself |
| --- | --- | --- |
| How do people understand a contested situation? | [Soft systems modelling](../methods/soft-systems-modelling.md) | A single objective problem definition |
| What relationships do stakeholders see? | [Participatory systems mapping](../methods/participatory-systems-mapping.md) | Representative or validated causal truth |
| Which feedback loops might matter? | [Causal loop diagrams](../methods/causal-loop-diagrams.md) | Effect sizes or calibrated dynamics |
| How does evidence update uncertainty? | [Bayesian belief networks](../methods/bayesian-belief-networks.md) | Feedback cycles in an ordinary DAG |
| What might emerge from interacting behaviours? | [Agent-based modelling](../methods/agent-based-modelling.md) | Reality without calibration and validation |
| What changed relative to a credible comparison? | [Difference in differences](../methods/difference-in-differences.md) | Validity without identification assumptions |
| Did a proposed mechanism operate in this case? | [Process tracing](../methods/process-tracing.md) | General effect size across all settings |
| How credible is the intervention's contribution story? | [Contribution analysis](../methods/contribution-analysis.md) | Exclusive attribution |
| How do we involve relevant practical expertise? | [Smarter Crowdsourcing](../methods/smarter-crowdsourcing.md) | Implementation or impact merely from participation |
| How should different intelligence inform deliberation? | [Policy steering rooms](../methods/policy-steering-rooms.md) | Better decisions merely from a display |
